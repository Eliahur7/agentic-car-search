# 🤖 Agentic Car Search Engine

Welcome to the **Agentic Car Search Engine**. Describe the car you are looking for in plain English (and what features you care about) and our intelligent search agent will find it for you across multiple platforms!

## ✨ Features

- **AI-First Natural Language Search**: Type exactly what you want (e.g., *"Looking for a reliable SUV under $35k with under 40k miles, adaptive cruise, and clean accident history"*).
- **Multi-Source Inventory**: Simulates pulling listings from CarGurus, Autotrader, Cars.com, Dealer Direct, and Manufacturer CPO.
- **Deal Value Evaluator**: Automatically tags listings as `🔥 Great Deal`, `🟢 Fair Price`, or `⚠️ Overpriced` compared to current market values.
- **5-Year Cost Estimator**: Breaks down the total cost of ownership including depreciation, maintenance, fuel, and insurance.
- **Dealer Advisor**: Generates tailored, high-leverage questions to ask the dealer before you go.
- **History Summarizer**: Instant summarization of accident history and service records.

## 🚀 Quick Start

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/Eliahur7/agentic-car-search.git
   cd agentic-car-search
   ```

2. **Set up a virtual environment**:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Application**:
   ```bash
   streamlit run app.py
   ```
